# 前言

在 [数据库及实现](https://elearning.fudan.edu.cn/courses/88334) 课程中，同学们已经打下了坚实的理论基础。然而，真正动手开始期末项目时，许多同学可能会感到迷茫：如何将课堂所学应用于实际项目？需要准备哪些开发工具？团队协作时该注意些什么？又该如何从零搭建一个完整的数据库应用系统？

本指南的目的，正是帮助大家理清思路，从容迈出实践的第一步。


## 开发工具

我们将从最基本的开发环境配置入手，介绍 [MySQL](./tools/mysql.md) 和 [VSCode](./tools/vscode.md) 的安装与使用。这两款工具是数据库开发的核心利器，能够帮助大家高效地编写、调试与管理代码，为项目开发打下坚实的技术基础。


## Git & GitHub

考虑到本课程的主要对象是大二学生，其中很多同学是 **首次参与团队项目开发**，我们将重点讲解 [Git 与 GitHub](./tools/git-and-github.md) 的使用。通过学习这些工具，同学们将掌握多人协作开发的核心技能，包括版本控制、分支管理、代码合并等。这些内容不仅适用于课程项目，也为将来的科研或工程开发积累宝贵经验。


## 项目示例

为了帮助大家更直观地理解数据库项目的开发流程，我们提供了一个基于 [Django](https://www.djangoproject.com/) 框架的 **完整示例项目**。该示例涵盖了从项目初始化、数据库配置，到数据表设计与管理、CRUD 功能实现，再到前端交互与数据序列化的全过程。每个环节均配有具体的代码解析，帮助大家快速上手。


## 其他内容

除了开发流程与工具介绍，我们还整理了期末项目的 [注意事项](./caution.md)，并收集了往届优秀作品的 [参考案例](./templates.md)。希望这些经验与示范，能够帮助大家避坑少走弯路，更高效地完成项目开发。
